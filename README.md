# Spotify PM Deck: Improving Conversion Rate

This repository contains research data, user survey insights, and the Product Management presentation deck focused on improving Spotify's Free-to-Premium conversion rate.

## Repository Contents

- **`Spotify_Deck.pdf`**: The main Product Management presentation deck covering problem framing, user research, friction analysis, solution proposals, metrics, and implementation roadmap.
- **`Music Streaming Apps Survey .xlsx`**: Primary quantitative survey dataset collecting user feedback on music streaming consumption habits, price sensitivity, and feature preferences.
- **`Spotify Research.docx`**: Secondary research notes, industry benchmarks, and literature references regarding freemium music streaming models.

## Overview

The goal of this project is to analyze Spotify's freemium conversion funnel, identify key drop-off points and willingness-to-pay barriers, and propose actionable product strategies to increase Premium subscriber conversion.
